STM32 学习笔记 · 从零开始的嵌入式入门（个人项目）2026.09 – 至今

github.com/shisisishi/stm32-learning-notes · C / gcc
  • 设计「电控 + 电路」双线学习路线（11 章）：电控线覆盖 GPIO → 定时器/PWM → 串口 → I²C → ADC → 通信协议 → PID 闭环；电路线覆盖限流分压 → 去耦与电源完整性 → 原理图 → PCB。
  • 独立编写脱离硬件的直流电机 + PID 仿真（电枢电气模型 + 机械模型，前向欧拉离散化，物理步长 20 µs / 控制周期 1 ms），一次运行输出 18 组参数对照的指标 CSV 与逐时刻波形 CSV。
  • 用该仿真量化验证了 PID 各参数的作用，例如：Kp 从 0.3 增至 8 时稳态误差由 19.20 降至 1.21 rad/s 但上升时间在 32 ms 处不再改善（受 12 V 电源限幅约束）；Kp=1/Ki=50 时关闭积分限幅会使超调由 1.09% 恶化到 44.04%；噪声下 Kd=0.001 使输出抖动由 1.69 V 放大至 4.73 V，加 τ=10 ms 一阶低通后回到 1.88 V。
  • 把结论写成 3 篇实验记录并公开原始 CSV，附带一条命令可复现的验证步骤。
  • 当前状态：硬件尚未到货，所有结论限定在「PC 上真实运行」范围内；上机实验列为下一阶段计划（外设逐章上机 → CAN 电机 → 底盘功率控制）。
